# 中文词汇游戏

一个面向中文初学者的多语言词汇练习网站。中文是学习目标语言，界面和释义支持英语、德语、法语、西班牙语和意大利语。

## 开始使用

```sh
npm install
npm run dev
```

生产构建：

```sh
npm run build
npm test
npm run test:e2e
```

## 功能

- 看汉字选拼音、看拼音选汉字、拼音与汉字配对、翻翻卡四种练习。
- 首页保留 10 / 20 题即兴练习入口；教师可管理词库、批量导入、选择词条并生成四种游戏。
- 词汇和具名练习保存在浏览器 `localStorage`，刷新后可继续编辑和使用。已保存练习通过词条 ID 引用统一词库；编辑词条会更新相应练习，删除词条会从练习选择中移除。
- 每题答对得 10 分；最高分保存在当前浏览器。
- 中文及五种翻译语言均使用浏览器原生 Speech Synthesis API 发音。浏览器和系统需提供对应语音；新播放会先停止前一段音频。
- 语速可选 0.75×、1.0× 和 1.25×。
- 共用词汇库维护汉字、带声调拼音、五种人工校对/可编辑翻译及图片来源元数据，游戏不会各自复制词条。批量格式为每行 `中文 | 拼音 | English | Deutsch | Français | Español | Italiano`；不自动猜测翻译。
- 自动拼音按需加载 `pinyin-pro`，依词语上下文处理多音字；教师可手动改写。少量正字法/专名形式单独规范（如“谢谢”“重庆”），生成后仍应核对。
- 自动翻译逐语种调用无密钥的 MyMemory 公共 API；直译无结果时尝试中文→英语→目标语中转。服务依赖网络及免费配额，机器译文不保证完全准确；失败语言会明确提示，手动修改的字段不会被覆盖。
- 正确答案 +1 星，连续答对第 3 题额外 +1、第 5 题额外 +2，完成当前游戏 +3。题目与练习在单次会话内去重；累计星星保存在 `localStorage` 的 `chineseVocabularyStars`。

## 图片搜索

- 图片搜索使用 Wikimedia Commons 官方 `api.php` JSON 接口，带 `origin=*` 进行浏览器匿名跨域请求，不需要 API 密钥，也不抓取搜索引擎网页。
- 搜索词由中文词语和英语释义组成；结果展示缩略图、作者、许可和 Commons 来源页。选择前请核对内容与具体许可条件，词条会保存来源及许可信息。
- 可手动填写图片 URL、替换或清除图片。内置词汇默认没有配图，不会用随机图片代替；图片加载失败时显示占位图。
- Commons 或网络不可用时搜索会给出提示，词汇编辑和练习不受影响。使用 Commons 图片仍须遵守图片各自的许可和署名要求。

## 导出 PDF

- 导出使用独立打印预览和 `window.print()`，在打印对话框中选择“另存为 PDF”；支持学习表、无答案学生练习册、教师答案版以及练习册附答案页。
- 完成练习后可导出结果版，包含练习名、词汇、得分、正确率和本次星星。
- 打印 CSS 使用 A4 页面、图片等比缩放和避免卡片跨页截断。页面等待 Web 字体和图片加载后再打开打印对话框。
- 中文字体优先使用 Noto Sans SC Web 字体；首次加载该字体需要网络。如果网络不可用，显示效果取决于操作系统已安装的中文字体。使用系统打印预览检查后再保存，确保目标设备的 CJK 字体与图片均已加载。

## 数据与隐私

- 词汇、练习、选中词条和最高分仅保存在当前浏览器的 `localStorage`；清理站点数据会删除它们，目前没有账号、云同步或自动备份。
- 图片搜索请求会发送搜索关键词到 Wikimedia Commons；不会发送本地词库或翻译字段。
- 自动翻译会把中文词语发送给 MyMemory；拼音在浏览器本地生成。无需配置私密 API Key。

## 手动验收

1. 运行 `npm run dev`，在首页切换五种翻译语言并确认四种游戏标题随语言变化。
2. 打开“词汇管理”，逐条添加一个词或粘贴七列批量数据；检查所有翻译字段、拼音和图片 URL 编辑，刷新后确认词条仍在。
3. 对词条执行“搜索图片”，确认 Commons 缩略图、许可、作者和来源页可见；选择图片后应显示在词条中。也可尝试清除或输入手动图片 URL。
4. 在“创建练习”中选至少四个汉字和拼音不重复的词，填写名称并生成；切换四种游戏，检查题目图片、不同选项、发音、答题反馈、进度、得分、重开和返回。
5. 打开“我的练习”，编辑或重新打开已保存练习；刷新后确认练习名、语言和词汇选择仍保留。
6. 分别预览学习表、学生练习册、教师答案版及练习册答案开关，在打印预览检查汉字、声调、图片、署名和分页，再选择“另存为 PDF”。
7. 用浏览器开发者工具切换到约 390px 宽度，检查导航、词条编辑、图片搜索结果、选词卡片和游戏操作按钮。
8. 运行 `npm test`，检查多音字、服务回退/错误、连胜奖励和重复领奖保护；再运行 `npm run build`。

浏览器端到端测试使用 Playwright/Chromium。首次运行执行 `npx playwright install chromium`；Linux 还需系统提供 Chromium 运行库，管理员环境可运行 `npx playwright install-deps chromium`。若当前容器缺少系统库且无安装权限，`npm test` 的服务/奖励测试和 `npm run build` 仍可运行，但 `npm run test:e2e` 无法启动浏览器。

## 项目结构

- `src/data/vocabulary.ts`：统一词汇数据。
- `src/data/translations.ts`：语言选项、界面文案和语音区域代码。
- `src/components/SpeechButton.tsx`：通用多语言发音按钮。
- `src/games/`：四种游戏模式。
